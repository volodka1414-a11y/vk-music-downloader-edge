# Моя музыка для VK — Microsoft Edge

Неофициальное расширение для скачивания добавленных треков из собственной **«Моей музыки» ВКонтакте** на **vk.ru**.

Скачивайте отдельные песни или запускайте последовательную загрузку списка. Расширение само прокручивает страницу, пропускает ранее успешно скачанные записи и открывает отчёт с результатами.

Проект создан с помощью ИИ. Расширение бесплатно и не связано с VK.

**[Скачать установочный ZIP](https://github.com/volodka1414-a11y/vk-music-downloader-edge/releases/latest)** · **[Сообщить об ошибке](https://github.com/volodka1414-a11y/vk-music-downloader-edge/issues/new/choose)**

## Возможности

- Кнопка «Скачать» рядом с треком.
- Массовое скачивание в папку «Моя музыка».
- Работа без автоматического запуска плеера.
- Автоматическое определение текущего аккаунта.
- Отдельная история загрузок для каждого аккаунта.
- Два круга повторных попыток при определённых временных ошибках после основного прохода.
- Остановка после текущего файла и возможность продолжения.
- Очистка имён файлов от смайликов и недопустимых символов.
- Отчёт со списком нескачанных треков и причинами ошибок.

## Совместимость

Разработано для **Microsoft Edge на Windows**. Ручные проверки проводились в Edge на Windows на предыдущих версиях проекта. Работа в Chrome, Яндекс Браузере, Opera и других браузерах не проверялась и не гарантируется.

Публичная сборка **0.14.1** прошла локальные проверки на искусственных данных. Проверка на реальном аккаунте другого пользователя пока не завершена.

## Установка

1. Откройте [страницу последнего выпуска](https://github.com/volodka1414-a11y/vk-music-downloader-edge/releases/latest).
2. В разделе **Assets** скачайте **vk-my-music-edge-public-0.14.1.zip**. Это готовый установочный архив; автоматически созданные GitHub архивы **Source code** для этой инструкции не нужны.
3. Распакуйте архив в постоянную папку.
4. В Edge откройте **edge://extensions**.
5. Включите **«Режим разработчика»**.
6. Нажмите **«Загрузить распакованное»** и выберите папку, в которой лежит manifest.json.
7. Откройте **vk.ru → «Моя музыка» → «Все»** и обновите страницу.

Не удаляйте и не перемещайте выбранную папку после установки. Дополнительные программы и сборка проекта не требуются. Расширение не опубликовано в магазине Edge Add-ons.

## Первый запуск

1. В меню расширений Edge откройте **«Моя музыка для VK — Edge»**.
2. Нажмите **«Разрешить согласованные CDN»** и подтвердите доступ, если браузер его запросит. CDN — серверы, с которых загружается аудио.
3. Вернитесь в свою музыку и попробуйте скачать одну песню кнопкой **«Скачать»**.
4. Откройте файл и проверьте песню, длительность и звук.

Расширение использует текущий аккаунт открытой страницы VK. Вводить в него пароль, cookies или токены не нужно. Работа с чужой библиотекой блокируется.

## Скачать всю мою музыку

Нажмите **«Скачать всю мою музыку»** в панели на странице VK.

Расширение начнёт обход основного списка и будет сохранять треки по одному в подпапку **«Моя музыка»** внутри настроенной папки загрузок Edge.

Во время обхода:

- держите вкладку VK открытой;
- не прокручивайте список вручную;
- не меняйте раздел, сортировку и аккаунт.

Для остановки нажмите **«Остановить после текущего файла»**. Уже начатый файл получит возможность завершиться. В некоторых случаях для продолжения потребуется кнопка **«Продолжить обход»**.

При определённых временных ошибках трек откладывается до конца основного прохода. Затем выполняются до двух дополнительных попыток. После завершения или остановки открывается отчёт.

## История загрузок

При повторном запуске очереди ранее успешно скачанные треки пропускаются, а ошибки проверяются заново.

История хранится локально и разделяется по аккаунтам. Она не синхронизируется между браузерами и компьютерами. Расширение не сканирует весь диск и не гарантирует обнаружение вручную перемещённых или удалённых файлов.

Явное одиночное скачивание может сохранить песню повторно.

## Формат и имена файлов

Поддерживаются прямые источники с типами audio/mpeg и audio/mp4. Они сохраняются как **.mp3** и **.m4a** соответственно, без перекодирования.

Обычное имя — **«Исполнитель — Название»**. Смайлики и недопустимые символы удаляются только из имени файла; метаданные в интерфейсе остаются исходными.

Если имя непригодно или браузер отклоняет его, предусмотрено резервное имя на основе ID трека.

## Ограничения

**Скачивание всей библиотеки без пропусков не гарантируется.**

Возможные причины отказа:

- запись недоступна в VK;
- используемый способ не получил ссылку на аудио;
- сервер вернул ошибку;
- загрузка была прервана;
- формат источника не поддерживается;
- структура страницы VK изменилась.

Отсутствие ссылки само по себе не доказывает недоступность песни. Недоступные записи не заменяются другими версиями.

Остановка с сообщением **«Новые треки не обнаружены; полнота библиотеки не подтверждена»** не означает, что расширение гарантированно дошло до конца списка. Поздняя подгрузка может быть пропущена.

HLS-потоки и преобразование форматов не поддерживаются.

## Обновление

1. Остановите очередь и дождитесь завершения текущего файла.
2. Распакуйте новую версию поверх файлов в той же папке.
3. В **edge://extensions** нажмите **«Перезагрузить»** у существующего расширения.
4. Обновите вкладку VK.

Не удаляйте расширение перед обновлением: это может привести к потере его локальной истории. Не заменяйте личную сборку публичной без отдельного плана переноса данных.

## Данные и разрешения

История, состояние очереди и отчёты хранятся локально в браузере. Расширение не отправляет их разработчику и не использует аналитику.

Разрешения нужны для чтения данных выбранных строк VK, определения аккаунта, сохранения файлов, хранения истории и восстановления очереди.

Доступ к аудиосерверам предоставляется отдельно. Согласованный набор: vkuseraudio.ru, vkuseraudio.net, userapi.com, vkuser.net, okcdn.ru, mycdn.me и их поддомены.

Неизвестные источники автоматически не разрешаются. Дополнительное объявление https://*/* позволяет запросить доступ к конкретному выбранному серверу; фактический доступ ко всем сайтам не запрашивается.
